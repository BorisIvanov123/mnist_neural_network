Task 3: Recognizing Handwritten Digits¶

In this task, we aim to build and train an artificial deep neural network (DNN) that can recognize and predict handwritten numbers. We will construct a feedforward neural network (FNN) comprising various functions to handle data preparation, parameter initialization, forward and backward propagation, model training, and evaluation.

What is a feedforward neural-network architecture?¶

A feedforward neural network is a type of artificial neural network where connections between the nodes do not form any cycles. In other words, information flows in one direction: from the input layer, through any hidden layers, and finally to the output layer. This acyclic structure means there are no feedback connections, where outputs are fed back into the network.

Visually representation: Input Layer → Hidden Layer 1 → Output Layer¶

In our case, the FNN will consist of an input layer, a hidden layer, and an output layer. The input layer will have 784 nodes (one for each pixel in the 28x28 images), the hidden layer will have 124 nodes (optimized for performance), and the output layer will have 10 nodes (corresponding to the digits 0-9).

How we will structure the architecture of the FNN for recognising (predicting) handwritten digits from the MNIST dataset?¶

Functions to structure our FNN:¶

1. Data Preparation¶

load_data(): Load the MNIST dataset.

flatten_images(): Prepare the images for the model input by flattening them.

split_target(): Splitting the data into target and features

split_train_test() Splitting the data into training,validation and testing

2. Initialization¶

initialize_parameters(input_size, hidden_size, output_size): Initialize the weights and biases.

  • input_size = 784: Because the images in the MNIST dataset are 28x28 pixels, resulting in a 784-dimensional (28x28=784).

  • hidden_size = 124: This value is chosen to balance model complexity and performance.

  • output_size = 10: Because there are numbers from 0-9 and this makes 10 total classes for prediction. If we lower the output_size we will get a lot of wrong predictions.

3. Forward Propagation:¶

relu(x): Apply the ReLU activation function. The ReLU (Rectified Linear Unit) activation function is used to introduce non-linearity into the network. Relu is used in the hidden layers of the neural network and it helps the network learn complex patterns in the data by introducing non-linearity

softmax(x): Apply the Softmax activation function. The Softmax activation function is used in the output layer of a classification network. It converts the raw output scores (logits) into probabilities that sum up to 1. Softmax ensures that the output values can be interpreted as probabilities.

forward_propagation(X, W1, b1, W2, b2): Computes the forward pass through the network, from input to output, using linear transformations and activation functions.

4. Loss Calculation¶

cross_entropy_loss(y_true, y_pred): Calculate the cross-entropy loss between the true values and the predicted ones.

5. Backward Propagation¶

relu_derivative(): This function computes the derivatives of the ReLU function.

apply_dropout(A, keep_prob): Apply dropout to the activations during training.

backward_propagation(X, Y, Z1, A1, Z2, A2, W1, W2): Compute the backward pass where we optimise the weights and biases by going from the output to the input.

6. Training Loop¶

update_parameters(W1, b1, W2, b2, dW1, db1, dW2, db2, learning_rate): This function updates the weights and biases.

train_neural_network(X_train, Y_train, X_val, Y_val, hidden_size, learning_rate, epochs, batch_size, lamb_reg, keep_prob, patience): Train the network using forward and backward propagation.

learning_rate_scheduler(epoch, initial_lr): Adjust the learning rate as training progresses.

7. Evaluation¶

calculate_accuracy(y_true, y_pred): Calculate the accuracy of the model.

evaluate_model(X_test, y_test, W1, b1, W2, b2): Evaluate the trained model on the test set.

Our FNN architecture will consist of the following layers:¶

Input Layer (784 nodes) → Hidden Layer 1 (124 nodes) -- ReLU Activation → Output Layer (10 nodes)

By carefully designing and training this feedforward neural network, we aim to achieve high accuracy in recognizing handwritten digits, leveraging the structured approach and parameter tuning outlined above.

# Function to load the data
def load_data():
    (X_train, y_train), (X_test, y_test) = mnist.load_data() # Load the MNIST dataset
    return X_train, y_train, X_test, y_test # Return the data in training and testing sets

# Function to Flatten the images
def flatten_images(X_train, X_test): 
    X_train = X_train.reshape(X_train.shape[0], -1) # Flatten the images by reshaping
    X_test = X_test.reshape(X_test.shape[0], -1) # Flatten the images by reshaping
    return X_train, X_test # Return the flattened images

# Function to One-hot encode the labels
def one_hot_encode(y, num_classes):  # One-hot encode the labels
    return np.eye(num_classes)[y] # Return the one-hot encoded labels

# Function to Normalize the data between 0 and 1 by dividing by 255
def normalize_data(X_train, X_val, X_test): # Normalize the data
    X_train = X_train / 255.0 # Normalize the data
    X_val = X_val / 255.0 # Normalize the data
    X_test = X_test / 255.0 # Normalize the data 
    return X_train, X_val, X_test # Return the normalized data

# Function to Split the data into training and validation sets
def split_data(X_train, y_train, validation_size=0.1667): # Validation size is 1/6th of the training data
    X_train, X_val, y_train, y_val = train_test_split(X_train, y_train, test_size=validation_size, random_state=42) # Split the training data into training and validation sets using sklearn and a random seed of 42 for reproducibility
    return X_train, y_train, X_val, y_val

Define the Neural Network¶

Neural Network Implementation¶

The neural network is implemented using the following components:

  1. Parameter Initialization: Random initialization of weights and biases.
  2. Activation Functions: ReLU for hidden layers and Softmax for the output layer.
  3. Forward Propagation: Computes the output of the neural network.
  4. Loss Function: Cross-entropy loss with L2 regularization.
  5. Backward Propagation: Computes the gradients of the loss function.
  6. Parameter Update: Updates the parameters using gradient descent.

# Function to initialize the parameters
def initialize_parameters(input_size, hidden_size, output_size):
    W1 = np.random.randn(hidden_size, input_size) * 0.01 # Initialize the first set of weights
    b1 = np.zeros((hidden_size, 1)) # Initialize the first set of biases
    W2 = np.random.randn(output_size, hidden_size) * 0.01 # Initialize the second set of weights
    b2 = np.zeros((output_size, 1)) # Initialize the second set of biases
    return W1, b1, W2, b2

# Define the activation functions
def relu(x): 
    return np.maximum(0, x) # ReLU activation function

# Define the derivative of the ReLU activation function
def relu_derivative(x):
    return np.where(x <= 0, 0, 1) # Derivative of the ReLU activation function

# Define the softmax activation function for the output layer
def softmax(x):
    exps = np.exp(x - np.max(x, axis=0, keepdims=True)) # Subtract the maximum value to prevent overflow
    return exps / np.sum(exps, axis=0, keepdims=True) # Softmax activation function

# Define the forward propagation step to compute the output of the neural network
def forward_propagation(X, W1, b1, W2, b2, keep_prob=0.8): # Forward propagation
    Z1 = np.dot(W1, X) + b1  # Compute the weighted sum of the inputs
    A1 = relu(Z1) # Apply the ReLU activation function
    D1 = np.random.rand(A1.shape[0], A1.shape[1]) < keep_prob # Dropout mask
    A1 = np.multiply(A1, D1) # Apply dropout
    A1 /= keep_prob # Scale the activations
    Z2 = np.dot(W2, A1) + b2 # Compute the weighted sum of the hidden layer
    A2 = softmax(Z2) # Apply the softmax activation function
    return Z1, A1, Z2, A2, D1 # Return the intermediate outputs

# Define the cross-entropy loss function which is derived from the maximum likelihood estimation.
def cross_entropy_loss(y_true, y_pred, W1, W2, lambda_reg): 
    m = y_true.shape[1]  # Number of samples
    log_likelihood = -np.log(y_pred[y_true.argmax(axis=0), range(m)] + 1e-8)  # Compute the log-likelihood
    loss = np.sum(log_likelihood) / m  # Compute the average cross-entropy loss
    reg_loss = (lambda_reg / (2 * m)) * (np.sum(np.square(W1)) + np.sum(np.square(W2)))  # Compute the regularization loss
    return loss + reg_loss  # Return the total loss (cross-entropy loss + regularization loss)

# Define the backward propagation step to compute the gradients of the loss function with respect to the parameters
def backward_propagation(X, Y, Z1, A1, Z2, A2, W1, W2, D1, keep_prob=0.8):
    m = X.shape[1] # Number of samples
    dZ2 = A2 - Y # Compute the gradient of the loss with respect to Z2
    dW2 = (1 / m) * np.dot(dZ2, A1.T) # Compute the gradient of the loss with respect to W2
    db2 = (1 / m) * np.sum(dZ2, axis=1, keepdims=True) # Compute the gradient of the loss with respect to b2
    dA1 = np.dot(W2.T, dZ2) # Compute the gradient of the loss with respect to A1
    dA1 = np.multiply(dA1, D1) # Apply dropout
    dA1 /= keep_prob # Scale the activations
    dZ1 = dA1 * relu_derivative(Z1) # Compute the gradient of the loss with respect to Z1
    dW1 = (1 / m) * np.dot(dZ1, X.T) # Compute the gradient of the loss with respect to W1
    db1 = (1 / m) * np.sum(dZ1, axis=1, keepdims=True) # Compute the gradient of the loss with respect to b1
    return dW1, db1, dW2, db2

# Define the function to update the parameters 
def update_parameters(W1, b1, W2, b2, dW1, db1, dW2, db2, learning_rate):
    W1 -= learning_rate * dW1 # Update the first set of weights
    b1 -= learning_rate * db1 # Update the first set of biases
    W2 -= learning_rate * dW2 # Update the second set of weights
    b2 -= learning_rate * db2 # Update the second set of biases
    return W1, b1, W2, b2

# Define the function to train the neural network
def train_neural_network(X_train, y_train, X_val, y_val, hidden_size, learning_rate, epochs, batch_size, lambda_reg, keep_prob, patience=10): # Train the neural network
    input_size = X_train.shape[1] # Input size
    output_size = y_train.shape[1] # Output size
    W1, b1, W2, b2 = initialize_parameters(input_size, hidden_size, output_size) # Initialize the parameters
    best_val_loss = float('inf') # Initialize the best validation loss
    patience_counter = 0 # Initialize the patience counter
    
    # Train the neural network
    for epoch in range(epochs):
        permutation = np.random.permutation(X_train.shape[0]) # Shuffle the training data
        X_train_shuffled = X_train[permutation] # Shuffle the training data
        y_train_shuffled = y_train[permutation] # Shuffle the training data
        
        # Loop over the training data in batches
        for i in range(0, X_train.shape[0], batch_size): # Loop over the training data
            X_batch = X_train_shuffled[i:i + batch_size].T # Get a batch of inputs
            Y_batch = y_train_shuffled[i:i + batch_size].T # Get a batch of outputs
            
            # Perform forward and backward propagation
            Z1, A1, Z2, A2, D1 = forward_propagation(X_batch, W1, b1, W2, b2, keep_prob) # Forward propagation
            dW1, db1, dW2, db2 = backward_propagation(X_batch, Y_batch, Z1, A1, Z2, A2, W1, W2, D1, keep_prob) # Backward propagation
            W1, b1, W2, b2 = update_parameters(W1, b1, W2, b2, dW1, db1, dW2, db2, learning_rate) # Update the parameters
        
        # Compute the validation loss
        Z1, A1, Z2, A2, _ = forward_propagation(X_val.T, W1, b1, W2, b2) # Forward propagation second time
        val_loss = cross_entropy_loss(y_val.T, A2, W1, W2, lambda_reg) # Compute the validation loss
        
        # Print the validation loss every 10 epochs and check for early stopping
        if epoch % 10 == 0: # Epoches are divisible by 10 because we want to print the loss every 10 epochs
            print(f"Epoch {epoch}, Val Loss: {val_loss}")
        
        # Early stopping
        if val_loss < best_val_loss: # Check if the validation loss has improved
            best_val_loss = val_loss # Update the best validation loss
            patience_counter = 0 # Reset the patience counter
        else: # If the validation loss did not improve
            patience_counter += 1 # Increment the patience counter
        
        # Break out of the loop if the validation loss does not improve for 'patience' epochs
        if patience_counter >= patience: # Check if the patience limit has been reached
            print(f"Early stopping at epoch {epoch}") # Print the early stopping message
            break # Break out of the loop
    
    return W1, b1, W2, b2 # Return the trained parameters

# Define the function to evaluate the model on the test set
def evaluate_model(X_test, y_test, W1, b1, W2, b2):
    _, _, _, A2, _ = forward_propagation(X_test.T, W1, b1, W2, b2, keep_prob=1.0)  # No dropout during evaluation
    predictions = np.argmax(A2, axis=0) # Get the predicted labels
    labels = np.argmax(y_test.T, axis=0) # Get the true labels
    accuracy = np.mean(predictions == labels) # Compute the accuracy
    return accuracy

Paramters used in the training of the neural network:¶

In the function train_neural_network, we used several parameters to control the training process of the neural network. Here is an explanation of each parameter and why it is a good choice for this project:

1. hidden_size=124:¶

Explanation: This parameter defines the number of neurons in the hidden layer of the neural network.

Justification: A hidden layer size of 124 provides a balance between model complexity and computational efficiency. It is large enough to capture the complexities of the MNIST dataset while avoiding overfitting and excessive computation time.

2. learning_rate=0.04:¶

Explanation: The learning rate determines the step size at each iteration while moving toward a minimum of the loss function.

Justification: A learning rate of 0.04 is chosen to ensure the network converges at a reasonable pace. It is not too high to cause overshooting of the minimum and not too low to cause slow convergence.

3. epochs=150:¶

Explanation: The number of epochs is the number of complete passes through the entire training dataset.

Justification: Setting the epochs to 150 allows the network sufficient opportunity to learn from the data. Early stopping is also implemented, so training may halt before reaching 150 epochs if validation loss stops improving, preventing overfitting. This can be seen in the early stopping mechanism and how our model stops training after the 99th epoch.

4. batch_size=64:¶

Explanation: The batch size is the number of training examples utilized in one iteration.

Justification: A batch size of 64 is a commonly used value that provides a good balance between convergence speed and stability of the gradient descent updates. It allows efficient computation using modern hardware like GPUs.

5. lambda_reg=0.01:¶

Explanation: This parameter is the regularization term, which helps prevent overfitting by penalizing large weights.

Justification: A regularization factor of 0.01 is chosen to effectively prevent overfitting without significantly hindering the learning capacity of the model. It helps in maintaining generalization performance.

6. keep_prob=0.8:¶

Explanation: The keep probability for dropout regularization, which randomly drops units (along with their connections) during training to prevent overfitting.

Justification: A keep probability of 0.8 means that 20% of the neurons are dropped during each training iteration. This value helps in making the network more robust and prevents over-reliance on particular neurons, enhancing generalization.

7. patience=10:¶

Explanation: The number of epochs to wait for an improvement in the validation loss before stopping the training early.

Justification: A patience value of 10 allows the model some flexibility to improve after a plateau in validation loss. It helps in preventing premature stopping while also ensuring that the model does not overfit by training for too long without improvement.

    return misclassified_as

    misclassified_as = most_commonly_misclassified_as(conf_matrix, digit)
